# 🌱 Projeto Cloud Seed

## 📌 Sobre o projeto

O **Cloud Seed** é uma aplicação desenvolvida em equipe como parte da disciplina de **Programação Orientada a Objetos (POO)** do curso de **Ciência da Computação**.

O projeto tem como objetivo auxiliar no cuidado e gerenciamento de plantas, oferecendo informações úteis para seus cuidadores, sejam eles iniciantes ou experientes.

A aplicação permite consultar informações relacionadas às necessidades de diferentes espécies de plantas, como:

- 💧 Necessidade de rega;
- ☀️ Exposição solar;
- 🌱 Tipo de solo;
- 🌿 Características e cuidados específicos de cada espécie.

Além de colocar em prática os conceitos de **Programação Orientada a Objetos**, o projeto também envolveu trabalho em equipe, organização do código, integração com APIs externas e desenvolvimento de uma solução com aplicação prática.

## 🛠️ Tecnologias utilizadas

- **Java**
- **Java Swing**
- **Perenual API**
- **WeatherAPI**

## 🔌 APIs utilizadas

### Perenual API

Utilizada para obter informações relacionadas às espécies de plantas e seus cuidados.

### WeatherAPI

Utilizada para obter informações meteorológicas que podem auxiliar nas recomendações relacionadas ao cuidado das plantas.
